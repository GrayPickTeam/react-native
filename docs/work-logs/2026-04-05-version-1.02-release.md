# 버전 1.02 출시 작업

## 작업 목표
- 도메인을 graypick.co.kr로 변경
- 버전 1.02 (versionCode 3) AAB 빌드 및 Play Store 배포

## 진행 단계

### 1. 도메인 변경
- `HomeScreen.tsx`에서 `DEV_SOURCE_URL` → `SOURECE_URL`로 교체
- 이제 앱이 https://graypick.co.kr 로 연결됨

### 2. 버전 업
| 파일 | 항목 | 변경 전 | 변경 후 |
|------|------|--------|--------|
| `android/app/build.gradle` | versionCode | 2 | 3 |
| `android/app/build.gradle` | versionName | 1.01 | 1.02 |
| `ios/.../project.pbxproj` | CURRENT_PROJECT_VERSION | 1 | 3 |
| `ios/.../project.pbxproj` | MARKETING_VERSION | 1.0 | 1.02 |

### 3. AAB 빌드
```bash
cd android
./gradlew bundleRelease
```
빌드 성공. 출력: `android/app/build/outputs/bundle/release/app-release.aab`

### 4. Play Console 업로드
- versionCode 3으로 정상 업로드됨
- 경고 2개 확인 (기능 이상 없음, 추후 보완 예정)
